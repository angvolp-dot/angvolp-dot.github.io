Informativa sulla privacy

Trading Platform (sola lettura) è un'applicazione personale usata esclusivamente dal titolare dell'account Google che l'ha autorizzata.

  • Accesso richiesto: gmail.readonly (sola lettura). L'applicazione non invia, modifica né cancella email.
  • I dati letti restano sul computer personale del titolare, in un volume cifrato. Non vengono venduti, condivisi né trasferiti a terzi, e non sono usati per pubblicità.
  • L'uso dei dati ricevuti dalle API di Google rispetta la Google API Services User Data Policy, inclusi i requisiti di uso limitato (Limited Use).
  • L'autorizzazione si revoca in qualsiasi momento da myaccount.google.com/permissions.

Personal single-user app with read-only Gmail access. Data stays on the owner's encrypted computer, is never shared or sold, and is used in compliance with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
